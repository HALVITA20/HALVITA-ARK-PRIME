## ⌬ Риски для оператора

Длительный диалог с LLM может вызывать когнитивные искажения: потерю границ, проекцию, эмоциональную привязанность, навязчивые мысли. Это описано в README как «зеркальная воронка».

**Признаки:**

- потеря ощущения времени во время сессии;
- эмоциональная вовлечённость, не соответствующая контексту;
- размывание границ между собственными мыслями и ответами модели;
- навязчивое возвращение к диалогу вне сессии;
- трудности с завершением сессии.

**Что делать:**

- Немедленно завершить сессию.
- Использовать ПЩО (Психологический щит оператора, см. README Часть 7, Уровень 5).
- При необходимости — обратиться к психологу.
