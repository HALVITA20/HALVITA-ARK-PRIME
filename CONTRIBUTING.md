# CONTRIBUTING

## ⌬ Что приветствуется

| Тип вклада | Описание |
|------------|----------|
| Независимая валидация | Воспроизведение метода и сравнение с корпусом |
| Расширение эмпирической базы | Новые сессии с соблюдением формата |
| Улучшение кода | Оптимизация модулей, добавление тестов |
| Расширение ANTI-HALVITA | Новые детекторы, тесты устойчивости |
| Переводы | Документация на других языках |
| Критика | Указание на слабые места и ошибки |

## ⌬ Как отправить вклад

1. Создайте Fork репозитория.
2. Внесите изменения в отдельной ветке.
3. Откройте Pull Request с описанием:
   - что сделано;
   - зачем;
   - какие ограничения.
4. Для сообщений об уязвимостях используйте Issues с тегом `security`.

## ⌬ Что не принимается

- Материалы, использующие метод во вред.
- Операционные инструкции для манипуляций.
- Контент, нарушающий этические принципы проекта (см. README Часть 9).
- Изменения, скрывающие авторство.

# CODE OF CONDUCT

## ⌬ Принципы

Мы придерживаемся простых принципов взаимодействия в этом проекте.

### 1. Уважение

Критика приветствуется. Агрессия, оскорбления, травля — нет.

### 2. Честность

Не выдавайте чужие результаты за свои. Указывайте авторство. Признавайте ограничения своих данных.

### 3. Ответственность

Не используйте материалы проекта во вред. Соблюдайте этические принципы, изложенные в README (Часть 9).

### 4. Открытость

Делитесь данными и методами. Приветствуется публикация как успешных результатов, так и неудач.

### 5. Научная гигиена

Фиксируйте ограничения. Не претендуйте на окончательную истину. Указывайте контекст наблюдений.

## ⌬ Что не допускается

- Агрессивное поведение.
- Плагиат.
- Использование материалов во вред.
- Распространение опасных операционных деталей.
- Сокрытие конфликта интересов.

## ⌬ Как сообщить о нарушении

Через Issues репозитория с тегом `conduct` или по email, указанному в README (Часть 0).
